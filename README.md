# Програмна частина лабораторних робіт з РСКП

Вбудоване програмне забезпечення системи аналізу коливань лука (XIAO ESP32-S3 Plus, сенсор BNO085),
тести його модулів оброблення сигналу та результати їх виконання. На цей каталог посилається звіт
до лабораторної роботи №5 «Алгоритми автоматизованого розв'язання. Програмна реалізація».

## Структура

| Каталог | Вміст |
| --- | --- |
| `firmware/` | вбудоване ПЗ (ESP-IDF, FreeRTOS); опис апаратури й модулів - `firmware/README.md` |
| `firmware/services/shot_detect/` | алгоритм виявлення пострілу |
| `firmware/services/stability/` | алгоритм оцінки стабільності утримання |
| `firmware/test/host/` | автоматизовані тести модулів на ПК і контрольний приклад |
| `tools/` | сценарій запуску тестів і скрипт перевірки та побудови графіків |
| `results/` | результати тестів, покриття, контрольного прикладу й графіки |
| `docs/ble/` | протокол обміну даними через BLE |
| `ci/` | конфігурація автоматичного збирання |

## Збирання вбудованого ПЗ

Потрібне встановлене середовище ESP-IDF. Бібліотеку драйвера сенсора esp32_BNO08x до каталогу не
включено (в оригінальному репозиторії це git-підмодуль): її потрібно розмістити в
`firmware/vendor/esp32_BNO08x`. Далі в каталозі `firmware`:

```sh
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

## Тести й контрольний приклад

Тести не потребують плати й ESP-IDF: модулі оброблення компілюються на ПК із заглушкою журналу.
Потрібні GCC, CMake і Ninja в `PATH` (результати в `results` отримано з GCC 15.2 (MSYS2), CMake 4.3,
Ninja 1.13). З каталогу `project`:

```powershell
powershell -ExecutionPolicy Bypass -File tools\run_host_tests.ps1 -Clean
```

Сценарій збирає й виконує тести `shot_detect_test`, `stability_test`, `imu_profile_test`, вимірює
покриття (gcov) і запускає контрольний приклад. Каталог збирання створюється в тимчасовій папці з
латинським шляхом: за шляхом із кирилицею інструментовані програми не можуть записати дані покриття.

Після цього скрипт `tools/analysis.py` (Python з NumPy, SciPy, Matplotlib) незалежно перевіряє
коефіцієнти фільтрів і обвідні контрольного прикладу та будує графіки:

```sh
python tools/analysis.py
```
